# 🩺 DiaPredict

**Diabetes risk prediction using an ensemble of machine learning models, with an interactive Streamlit web app.**

🔗 **Live demo:** [https://diapredict-ml.streamlit.app/](https://diapredict-ml.streamlit.app/)

> ⚠️ DiaPredict is an educational student project. It is **not** a medical diagnosis tool and must not be used for real medical decisions.

---

## Overview

DiaPredict estimates a person's risk of diabetes from eight health measurements. Instead of relying on a single algorithm, it trains four different models, tunes each one, and then combines them into ensembles to get a more stable and accurate prediction.

The project was built for a Machine Learning course, and it covers data preparation, leakage prevention, supervised learning, ensemble learning and basic deployment practices.

## Features

- **Four tuned algorithms:** Logistic Regression (L1/L2), SVM (linear/RBF), Random Forest and XGBoost
- **Two ensembles:** soft Voting and Stacking
- **Leakage-safe preprocessing:** train/test split first, then imputation and scaling inside a scikit-learn `Pipeline`
- **Multipage Streamlit app:**
  - **Home:** project summary and headline stats
  - **Predict:** live risk gauge, per-model votes, what-if explorer, comparison with dataset averages, health tips and a downloadable summary
  - **Model Insights:** metrics table, ROC curves, confusion matrices, feature importance
  - **Explore Data:** class balance, missing values, distributions, correlations
  - **How It Works:** the full pipeline explained, with syllabus mapping and limitations

## Dataset

[Pima Indians Diabetes Database](https://www.kaggle.com/datasets/uciml/pima-indians-diabetes-database): 768 records, 8 features, binary target (`Outcome`).

| Feature | Description |
|---|---|
| Pregnancies | Number of pregnancies |
| Glucose | Plasma glucose concentration |
| BloodPressure | Diastolic blood pressure (mm Hg) |
| SkinThickness | Triceps skin fold thickness (mm) |
| Insulin | 2-hour serum insulin (mu U/ml) |
| BMI | Body mass index |
| DiabetesPedigreeFunction | Family history score |
| Age | Age in years |

In glucose, blood pressure, skin thickness, insulin and BMI, a value of `0` is physiologically impossible, so zeros in those columns are treated as missing values and filled with the training-set median.

## How it works

```
Pima data → clean & split → impute + scale (Pipeline) → tune 4 models (5-fold CV)
          → Voting / Stacking ensembles → evaluate on held-out test set → Streamlit app
```

1. **Split first:** 80% train / 20% test, stratified, before any preprocessing.
2. **Pipeline:** median imputation and standard scaling are fit only on training data, which prevents preprocessing leakage.
3. **Tuning:** each model is tuned with `GridSearchCV` using stratified 5-fold cross-validation and ROC-AUC as the score.
4. **Ensembling:** the tuned models are combined by soft Voting and by Stacking with a Logistic Regression meta-learner.
5. **Evaluation:** Accuracy, Precision, Recall, F1 and ROC-AUC on the test set. Recall gets special attention, since missing a real case is the costly error in screening.

You can see the actual results on the **Model Insights** page of the app.

## Run it locally

**1. Clone and install**
```bash
git clone https://github.com/mohitto099/DiaPredict.git
cd DiaPredict
pip install -r requirements.txt
```

**2. (Optional) Retrain the models**

The repo already includes trained models. To retrain from scratch:
```bash
python train.py
```
This reads `data/diabetes.csv` and writes everything to `models/`.

**3. Start the app**
```bash
python -m streamlit run app.py
```
Then open the local URL that Streamlit prints (usually http://localhost:8501).

## Tech stack

Python, pandas, NumPy, scikit-learn, XGBoost, Plotly, Streamlit, Git/GitHub, Streamlit Community Cloud.

## Limitations

- The dataset is small (768 records) and comes from one population, so results may not generalise to other groups.
- Insulin and skin thickness have many missing values that are filled with medians.
- The tool estimates risk from a few numbers and cannot replace a blood test or a doctor.
